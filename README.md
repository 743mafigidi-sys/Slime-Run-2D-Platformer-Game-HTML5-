🟢 Slime Run

Slime Run is a 2D platformer where you play as a small but brave slime! Jump across platforms, fight enemies, avoid dangerous traps, defeat powerful bosses, and explore exciting levels on your adventure.

🎮 Features

- 🟢 Dynamic 2D platformer gameplay.
- ⚔️ Enemies and boss battles.
- 🗺️ Multiple levels and environments.
- 🦘 Jumping, attacking, and movement mechanics.
- ❤️ Health system.
- 🏆 Game progress saving.
- 📱 Mobile-friendly touch controls.
- 🔊 Sound effects and background music.

🕹️ Controls

The game supports touchscreen controls for mobile devices.

💻 Built With

- HTML5
- CSS3
- JavaScript

🚀 How to Play

1. Download or clone this repository.
2. Open "index.html" in your browser.
3. Start your adventure!

📌 About

Slime Run is a 2D platformer game project built with HTML, CSS, and JavaScript.
